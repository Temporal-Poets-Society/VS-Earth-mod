# European gypsum evidence correction — 29 September 2026

The previous worldwide occurrence map substantially underrepresented European gypsum. Absence of points in that map was a **coverage gap**, not evidence that gypsum is absent. This correction combines actual deposit boundaries, historical and noncommercial occurrences, and independently mapped mineral-bearing formations. It applies no active-mine, profitability, minimum reserve, grade or shallow-depth filter. It does not change runtime generation.

## Integration files

- `normalized/gypsum-reviewed.geojson`: 525 source features, including 2 Latvian legal deposit polygons, 1 overlapping Latvian licensed subarea, 19 Polish documented/historical deposit polygons, 492 Spanish indication/workings points, and 11 independently reviewed British localities. Counts are **records**, not independent deposits.
- `normalized/gypsum-permissive-formations.geojson.gz`: full-resolution transformed formation/resource geometry, including all 25,541 matching IGME GEODE units; source-native geometry remains in `raw/`. Read `validation.json` for final country/source counts and geometry issues.
- `normalized/gypsum-permissive-formations-display-only.geojson`: separately simplified by 0.005 degrees with topology preservation, explicitly **not for generation**. This tolerance is for a regional/world overview, not a site or deposit-boundary map. Zoomed local maps should use the unsimplified sources.
- `normalized/latvia-legal-boundaries-native.json`: exact source coordinate rows and native polygons, including the source axis order.
- `reviewed-bgs-localities.json`: reviewable transcription of report grid references and factual mineral observations.
- `spain-reviewed-unit-descriptions.csv`: complete selection vocabulary, so a reader can see which mixed lithologies matched.
- `download-manifest.json`: exact requests and SHA256 checksums. `raw/` preserves official service metadata, original projections/attributes, legal coordinate tables and primary reports.
- `known-region-audit.csv`: where this correction has usable geometry, weaker evidence, or unresolved gaps.

All output features include `source_id`, `source_feature_id`, `source_url`, `country`, `name`, `mineral_identity`, `evidence_kind`, `source_crs`, `geometry_valid`, and `absence_evidence=false`. Depth endpoints and probabilities are deliberately null where unmeasured. Full outputs retain original attributes. `gypsum_spawn_evidence_withheld=true` flags anhydrite-only units and the extensively dissolved German units: these are contextual evidence and must not be colored as confirmed intact gypsum. Invalid geometry is preserved and flagged, not silently repaired or approved for generation.

The Spanish query contains no negative/dissolution-only descriptions; the German review explicitly retains that distinction.

## Known gaps and withheld sources

The current correction is substantially better for Europe, but is not a complete European gypsum map. Latvia still needs a reusable, continuous subsurface **Salaspils Formation** map and specific historical Saurieši/Zvejnieki boundaries. The legal Salaspils polygon should not be renamed Saurieši. France outside Île-de-France, Germany outside Baden-Württemberg (particularly the southern Harz and other Zechstein districts), Italy/Sicily, eastern/southeastern Europe and many offshore/deep basins remain incomplete here. Poland's MIDAS deposit polygons are not the whole Nida Basin or all deep Zechstein sulphate-bearing units.

BGS publishes gypsum resource linework, but the inspected ArcGIS service is Map-only and reports NERC copyright; the [digital resource licensing page](https://www.bgs.ac.uk/mineralsuk/exploration-and-maps/digital-licensing/) requires a licence. The failed query responses are retained as failures, not empty geological coverage. British formation extents remain unfilled rather than inventing polygons.

LGRB MIN4EU supplies mapped gypsum/anhydrite prospective polygons. Its government catalogue has an `opendata` tag but also a machine-readable `other-closed` licence classification, without a clear licence grant in the inspected service. Those raw research responses are retained, but **not normalized into the distributable atlas** pending clarification of the specific dataset terms. The independently open-licensed GKBW dataset is used instead. A source being publicly readable is not proof that every derivative can be redistributed.

The optional Spanish 1:1,000,000 lithology extract (869 mixed-unit polygons) is preserved in raw as a coarser comparison only; it is not added on top of GEODE and double-counted.

## Reproduction and interpretation

Run `python fetch_gypsum_sources.py --geode`, then `python normalize_gypsum.py` and `python validate_gypsum.py`. The fetch script uses only the standard library; the normalizer requires pyogrio, shapely and pyproj. It uses existing isolated research installations if present and does not install packages or alter game files. For GDAL's Esri polygon organization, ring topology is read by the driver; native unmodified responses remain authoritative. Transformation accuracy/operations are recorded in `validation.json`.

The full query result is checked against its independent source OBJECTID list, and all selected descriptive vocabulary is exported. Keep records/formation patches separate from independent deposits. Do not infer relative abundance directly from feature count: detailed Spanish mapping has many more polygons than a coarse overview elsewhere. Do not convert unknown depth into shallow depth, a processing site into natural occurrence, or a blank map into zero probability. These are positive evidence inputs for later generation and hypothesis testing, not calibrated global ore probabilities.
