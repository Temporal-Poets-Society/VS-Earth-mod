For Earth 1.0.x only. Earth 2.0 no longer uses this mod: it is one mod and downloads its own data the first time a server starts. Keep Earth Terrain Data only for a world made with Earth 1.0.x, together with Earth 1.0.x and Earth Water Data of the same version.

If it is still installed with Earth 2.0, it does no harm: Earth copies the files it needs from it instead of downloading them. For Earth 2.0, see the Earth page.
